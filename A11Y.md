# Accessibility tooling

- **`npm run lint`** — includes `eslint-plugin-jsx-a11y` recommended rules on `**/*.{js,jsx}` (with `ul: ['list']` allowed for explicit `role="list"` on lists in flex layouts).
- **`npm run a11y`** — runs `vitest` on [`src/a11y/routes-a11y.test.jsx`](src/a11y/routes-a11y.test.jsx): renders each public route in jsdom and runs **axe-core** via **jest-axe**. Color contrast is disabled in that run because jsdom does not compute real colors; validate contrast with [WAVE](https://wave.webaim.org/) or a browser extension on the deployed site.

## Manual check

After deploy, run WAVE on: `/about`, `/dashboard`, `/team`, `/partners`, `/docs`, `/outputs`.
